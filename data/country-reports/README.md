# Country Reports

One markdown file per country, per visit. When the vehicle visits a town and runs
the course, the team writes a short report here. If the trip returns to the same
country later, that return is a new file, not an edit to the old one. This keeps an
honest record of each stop that the [Phase 1A report](../phase-1a-report.md) and
grant applications can draw on.

## How to add one

1. Copy [`_TEMPLATE.md`](./_TEMPLATE.md) to a new file.
2. Name it `country-city-YYYY-MM.md`, for example `togo-lome-2026-03.md`. Use
   lowercase, hyphens, the ISO-style country name, the city, and the year and
   month of the visit.
3. Fill in every section. Leave `[CONFIRM]` where you do not yet have a number.
4. Add a matching row to the [dashboard](../dashboard.csv) so the totals stay in
   step.

## Files here

- [`_TEMPLATE.md`](./_TEMPLATE.md), the template to copy. Do not report in this
  file.
- One report per visit will appear here as the trip runs.
