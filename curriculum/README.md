# The two-day curriculum

A complete Bitcoin field course condensed from the
[BitKwa Bitcoin Diploma](../ATTRIBUTION.md) into two teachable days.

- **Day 1, the learner day.** Open to everyone. By the end, each person holds
  their own Bitcoin, has written down a seed phrase, has received and sent sats
  over Lightning, and has bought something real from a merchant.
- **Day 2, the ambassador day.** For the people who will keep teaching after the
  trip leaves. They go deeper on self-custody and safety, learn to run a session,
  onboard a merchant, and take on the ambassador commitment.

Each session folder contains:

| File | Purpose |
|------|---------|
| `facilitator-guide.md` | Minute-by-minute plan for the teacher: objectives, talking points, timings, common questions |
| `slides.md` | Projectable slides in [Marp](../tools/build-slides.md) markdown (renders to PDF, PPTX or HTML) |
| `handout.md` | One page the learner keeps |
| `exercise.md` | The hands-on activity for the session |
| `quiz.md` | Five questions, used for the ambassador badge, not for pass or fail |

## If you only have two hours

Run the [one-session version](./one-session): money, what Bitcoin is, a wallet,
and one real Lightning payment. This is the market or school session the team
runs when there is no time for a full day.

## Going deeper

This course is deliberately practical and short. For full depth, point learners
to the upstream [BitKwa Bitcoin Diploma](../ATTRIBUTION.md), the
[PlanB Network](https://planb.network) courses, and
[My First Bitcoin](https://myfirstbitcoin.io). The technical background is
summarised in the ["how it works" handout](./day-2/session-6-self-custody/handout.md)
and career paths in the ["what next" note](./day-2/session-10-ambassador-commitment/handout.md).

## A note on what this is not

This is not the Diploma. There is no 8-week schedule, no attendance requirement,
no graded tests, no graduation and no certificate here. Learners earn an
**ambassador badge by doing**: setting up a wallet, making real payments,
onboarding a merchant, and teaching others.
