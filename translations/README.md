# Translations

This is the home for every language version of the *Sats On The Road* curriculum.
The goal is simple: a learner should be able to hold a handout in a language they
read comfortably.

Start here:

- **[Translation Guide](./TRANSLATION-GUIDE.md)**, what to translate first, how to
  keep words consistent, and how to submit from a phone.
- **[Glossary](./GLOSSARY.md)**, the shared Bitcoin vocabulary. Translate this
  first; everything else depends on it.

## Languages

One folder per language, named with its ISO code. More will be added as partner
communities choose them.

| Language | Code | Folder |
|----------|------|--------|
| French | `fr` | [`fr/`](./fr/) |
| Twi | `tw` | [`tw/`](./tw/) |
| Fon | `fon` | [`fon/`](./fon/) |
| Ewe | `ewe` | [`ewe/`](./ewe/) |
| Mooré | `mos` | [`mos/`](./mos/) |

More languages (for example those of Côte d'Ivoire, Liberia and Sierra Leone)
will be added with their ISO codes as partners choose them. To start a new one
open an
["Offer a translation" issue](../.github/ISSUE_TEMPLATE/offer-a-translation.md).

Each language folder has a `README.md` with its status and a checklist of what to
translate first.
