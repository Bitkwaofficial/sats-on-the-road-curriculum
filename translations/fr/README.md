# French (`fr`)

**Status:** [not started / in progress]

This folder holds the French translation of the *Sats On The Road* curriculum.
Before you start, read the [Translation Guide](../TRANSLATION-GUIDE.md) and the
[Glossary](../GLOSSARY.md).

## What to translate first

Work in this order:

- [ ] **Glossary terms**, agree one French word per term in
  [`../GLOSSARY.md`](../GLOSSARY.md). French is partly filled in already; improve
  it where a better local usage exists.
- [ ] **Day 1 handouts**, the one-page sheets learners hold on the first day.
- [ ] **Merchant sign**, the printable "Bitcoin accepted here" sign.
- [ ] **Consent form**, the photo and video consent form. Translate this
  carefully and ask if anything is unclear.

Other pieces (full slides, playbook, safety material) come after these four.

To offer help, open an
["Offer a translation" issue](../../.github/ISSUE_TEMPLATE/offer-a-translation.md).
