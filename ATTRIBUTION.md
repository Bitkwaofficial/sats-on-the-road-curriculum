# Attribution and lineage

This curriculum is derived from the **BitKwa Bitcoin Diploma**, an 8-week
practical Bitcoin program built by BitKwa for African learners.

- **Upstream:** BitKwa Bitcoin Diploma, `https://github.com/Bitkwa/bitkwa-bitcoin-diploma`
- **This project:** Sats On The Road field curriculum and ambassador playbook,
  `https://satsontheroad.africa`
- **License:** upstream is MIT; this project keeps MIT for code and adds
  [CC BY 4.0](./LICENSE-CONTENT.md) for teaching material.

## What changed

The Diploma is a multi-week classroom program with attendance, assessments,
graduation and certification. This project condenses the teaching core into a
**two-day field format** that a local educator can run in a town along the route,
and adds the operational material the road trip needs: an ambassador playbook, a
merchant kit, safety and consent material, translations and field reporting.

The 8-week / weekly-assessment / graduation structure of the Diploma is **not**
part of this project. Learners here earn an ambassador badge by doing, not a
graded certificate.
