# The "Bitcoin accepted here" sign

The counter sign a merchant puts up to show they take Bitcoin.

- **Size:** A4.
- **Files:** it exists as a print-ready **PDF** at [`../bitcoin-accepted-here.pdf`](../bitcoin-accepted-here.pdf), and as an editable **HTML** source at [`../bitcoin-accepted-here.html`](../bitcoin-accepted-here.html).
- **Local language:** the sign has a blank line for the local-language version of "Bitcoin accepted here". Fill it in before printing. See [translations](../../translations) for the agreed wording per language.
- There is also a blank line for the shop name, and a marked box for the merchant's own payment QR. Drop the QR in before printing.

## How to print it

- Open [`../bitcoin-accepted-here.html`](../bitcoin-accepted-here.html) in a browser and choose **Print, then Save as PDF** at **A4**.
- Or print the ready-made [`../bitcoin-accepted-here.pdf`](../bitcoin-accepted-here.pdf) directly at A4.
