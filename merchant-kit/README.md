# Merchant Kit

Everything a merchant needs to start taking Bitcoin, and everything the team and
ambassadors need to onboard them. All pieces follow the Sats On The Road brand
(cream canvas, near-black ink, orange `#F7931A`, the logo).

## Printable pieces

Each comes as an editable **HTML** source, a print-ready **PDF** (A4), and a
**PNG** preview. Drop the merchant's own QR into the marked box before printing.

| Piece | Print | Preview | Source |
|-------|-------|---------|--------|
| "Bitcoin accepted here" sign (A4) | [PDF](./bitcoin-accepted-here.pdf) | [PNG](./bitcoin-accepted-here.png) | [HTML](./bitcoin-accepted-here.html) |
| QR table stand (fold) | [PDF](./qr-table-stand.pdf) | [PNG](./qr-table-stand.png) | [HTML](./qr-table-stand.html) |
| Sticker sheet (6 up) | [PDF](./sticker-sheet.pdf) | [PNG](./sticker-sheet.png) | [HTML](./sticker-sheet.html) |

To re-print after editing an HTML source, open it in a browser and choose
**Print → Save as PDF (A4)**, or regenerate with the project's render step.

## Localising the sign

The sign has a blank line for the shop name and a blank line for the local-language
version of "Bitcoin accepted here". Fill both before printing. See
[translations](../translations) for the agreed wording per language.
