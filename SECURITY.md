# Security policy

## Reporting a problem

Found a security or privacy problem in this repository? Please report it privately,
do not open a public issue.

- Email: **bitkwaofficial@gmail.com** with "SECURITY" in the subject.

We acknowledge within a few days and keep you posted while we fix it.

## What must never be committed here

- API keys, tokens, passwords, wallet seeds or xpubs, or any admin key.
- **Personal data:** names, phone numbers, emails or photos of ambassadors,
  merchants, activists, journalists or partner contacts, in files or commit
  messages. Ambassador reports use an **ID, not a name**; the ID-to-name map and
  the team's emergency contacts live in private files, not in this repo.
